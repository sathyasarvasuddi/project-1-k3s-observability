
# Kubernetes Observability Platform

## Project Overview

Building a production-style Kubernetes observability
platform using k3s, Prometheus, Grafana, OpenTelemetry,
Loki and Tempo.

## Project Objectives

- Deploy containerized Python microservices.
- Integrate PostgreSQL.
- Implement metrics, logs and distributed tracing.
- Configure SLI, SLO and burn-rate alerting.
- Perform load testing and failure drills.
- Automate validation using GitHub Actions.

## Technology Stack

- Kubernetes (k3s)
- Docker
- Helm
- Prometheus
- Grafana
- Alertmanager
- OpenTelemetry
- Loki
- Tempo
- Python
- PostgreSQL
- k6
- GitHub Actions
